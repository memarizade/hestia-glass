# Changelog

## 1.0.0

- Initial release.
- Grouped sidebar with icons and live counters for admin and customer accounts.
- Tile home page at `/home/` with category sections and search.
- Glass theme with readable form text, calm hover states, and alert styling.
- Inter font, self-hosted.
- `install.sh` with version check, backup, PHP syntax check, and automatic restore on failure.
